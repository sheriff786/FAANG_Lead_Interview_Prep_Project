  • Zustand 4.5 — State management
  • Axios 1.7 — HTTP client
  • react-markdown 9.0 — MD rendering

  • Python 3.12 — Core language
  • FastAPI 0.115 — Async web framework

  • LangChain 0.3 — LLM abstraction
